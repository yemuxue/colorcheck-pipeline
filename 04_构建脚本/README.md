# 出图检查清单

每张图导出前逐条过，不合格不发。

## 几何

- [ ] 连线坐标由常量推导，不手写数字（框中心 = x + w/2）
- [ ] 箭头端点落在框边或框中心线上，误差 ≤ 1px
- [ ] 汇流线（一分多 / 多合一）的拐点与分支点在同一 y
- [ ] 线与线不重叠成双线；T 形接头不超出 3px

## 排版

- [ ] 文字不溢出框、不压线、不与相邻文字重叠
- [ ] 左右留白一致（本仓库统一 100px）
- [ ] 画布底部不被裁切，注释距底边 ≥ 60px
- [ ] 同类元素尺寸一致（缩略图、卡片、行高）

## 视觉

- [ ] 浅色底、深色字，对比度足够
- [ ] 主色只用一种（蓝），强调色只用于结论行
- [ ] 无大片空白；内容区占比 ≥ 70%

## 验收

- [ ] 导出后放大 2× 抽查两处接头（箭头 + 拐点）
- [ ] 缩略图与正文数据一致（数字来自仓库，不手填）
